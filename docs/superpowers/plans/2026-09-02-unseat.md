# Unseat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a local-only Windows sitting-break reminder: always-on-top Direct2D timer, system tray, idle/lock-aware sitting engine, optional autostart.

**Architecture:** One Cargo package with a pure library (`SittingEngine`, `Settings`, view formatting) and a Win32 binary host. The host feeds clock, last-input age, and lock state into the engine and paints whatever the engine returns. No sitting rule lives in Win32.

**Tech Stack:** Rust 2021, `windows` crate (Win32 only), `serde` + `serde_json` for one settings file. No UI toolkit, no .NET, no Electron.

## Global Constraints

- Windows 10/11 x64; Rust + native Win32 only
- No .NET, Electron, WebView, or UI toolkit (no Slint/egui/iced)
- Single process, single instance (named mutex)
- Standalone `.exe`, no extra runtime install
- Near-zero idle CPU: 1 Hz logic tick, paint only on change
- Target idle RAM: about 5–15 MB
- Local data only, under `%APPDATA%\Unseat`
- Git commits are **skipped** until the owner provides Git identity; do not run `git config`
- Dependencies: `windows`, `serde`, `serde_json` only

```rust
pub struct EngineConfig {
    pub sitting_limit: Duration,
    pub break_duration: Duration,
    pub idle_after: Duration,
    pub sound_enabled: bool,
    pub repeat_reminders: bool,
    pub repeat_every: Duration,
}

#[derive(Clone, Copy)]
pub struct Input {
    pub last_input_age: Duration,
    pub session_locked: bool,
}

pub enum Command { TogglePause, Reset }

pub enum VisibleState { Sitting, Overdue, Break, Paused }

pub enum Beep { None, LimitReached, Progressive }

pub struct Snapshot {
    pub state: VisibleState,
    pub sitting_elapsed: Duration,
    pub break_elapsed: Duration,
    pub break_remaining: Duration,
    pub today_sitting: Duration,
    pub running: bool,
}

pub struct TickResult { pub beep: Beep, pub snapshot: Snapshot }

impl SittingEngine {
    pub fn new(config: EngineConfig, today: CivilDate, today_sitting: Duration) -> Self;
    pub fn set_config(&mut self, config: EngineConfig);
    pub fn apply(&mut self, cmd: Command);
    pub fn tick(&mut self, now: Duration, date: CivilDate, input: Input) -> TickResult;
    pub fn snapshot(&self) -> Snapshot;
}
```

`now` is a monotonic duration from an arbitrary origin. First `tick` uses `dt = 0`.
